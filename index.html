Backup

Automatic backup

Copies your customers, estimates and photos to a private GitHub repository every time something changes, and brings them back if this phone is ever replaced. One-time setup, about five minutes.

  1. On github.com, signed in as tcstaining-ctrl, make a new repository named TCS-Lights-data. Set it to Private and check Add a README.
  2. Go to Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. Name it "TCS Lights backup", set expiration to the longest allowed, and under Repository access pick Only select repositories and choose TCS-Lights-data.
  3. Under Permissions, Repository permissions, set Contents to Read and write. Generate the token and copy it.
  4. Paste it below and tap Turn on.

Save a backup file

A backup file holds your list, estimates, prices, notes, texts and rates, but not photos. Email it to yourself or keep it in Files.
